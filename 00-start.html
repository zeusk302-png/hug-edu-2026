01 · 완성 모습 먼저 보기

오늘 끝에 남는 것은 "확인까지 끝낸 문서"입니다

첫 단원은 워밍업입니다. 오늘 만들 결과가 어떤 모양인지 보고, 파일을 받고, 원본과 작업 사본을 나누는 것까지 합니다.

아래는 오늘 여러분이 실제로 만들게 될 것들입니다. 아직 만들지 않았습니다. 지금은 "이런 게 나온다"만 보고 넘어갑니다.

02 · 알아 둘 세 가지

오늘 계속 나오는 구분 세 가지

기능 이름을 외울 필요는 없습니다. 대신 아래 세 가지 구분은 오늘 내내 쓰입니다.

① 파일 이름과 확장자

파일 이름 끝의 점 뒤 글자가 확장자입니다. 그 파일을 무엇으로 여는지 정합니다.

확장자무엇인가오늘 어디서
.zip여러 파일을 하나로 묶어 압축한 것스킬 등록, 자료 묶음
.md글과 제목이 든 텍스트 파일. 메모장으로 열립니다회의록
.csv쉼표로 칸을 나눈 표 파일. 엑셀로도 열립니다설문, 기준표
.xlsx / .docx / .pptx엑셀 / 워드 / 파워포인트 문서모듈 02~04
.pdf / .png문서 이미지 / 그림 파일모듈 06~07

Windows에서 확장자가 안 보인다면: 탐색기 → 보기 → 파일 확장명 체크. 오늘은 확장자를 보고 골라야 하는 순간이 여러 번 나옵니다.

② 스킬 ZIP과 자료 ZIP

스킬 ZIP · 등록하는 것

등록할 때는 압축을 풀지 않습니다

안에 "이렇게 일해 달라"는 지시문이 들어 있습니다. 설정 화면에서 ZIP 파일 자체를 업로드합니다.

예: meeting-brief.zip, file-sort-plan.zip

규칙을 직접 고칠 때(모듈 01 06단계)만 예외입니다. 그때는 ZIP을 복사한 편집용 사본을 풀어 글을 고치고 폴더째 다시 압축해 새 이름으로 등록합니다. 등록용 원본 ZIP은 그대로 둡니다.

자료 ZIP · 첨부하는 것

압축을 풀어서 씁니다

안에 이번에 처리할 회의록·표·사진이 들어 있습니다. 풀어서 대화에 파일을 첨부합니다.

예: meeting-notes-5.zip, 영수증_이미지3장.zip

이 둘을 바꿔서 하면 실패합니다. 자료 ZIP을 등록 화면에 올리면 등록 오류가 나고, 스킬 ZIP을 대화에 첨부하면 스킬이 켜지지 않습니다. 오늘 가장 흔한 첫 실수입니다. 정리하면 — 등록: ZIP 그대로 · 첨부: 풀어서 · 직접 고치기: 사본을 풀어 고치고 다시 압축. 세 가지는 다른 행동입니다. 기능 지도 04절

③ 원본과 작업 사본

AI에게 폴더를 맡기는 실습(모듈 05)에서는 실제로 파일이 바뀔 수 있습니다. 그래서 원본은 따로 두고 복사본에서 작업합니다.

구분어디에 두나무엇을 하나
원본받은 그대로의 폴더. 이름에 _원본을 붙여 두면 좋습니다읽기만 합니다. 틀렸을 때 돌아올 자리입니다
작업 사본원본 폴더를 복사해 만든 폴더AI에게 연결하고 정리·수정을 시킵니다

"스킬에 원본을 고치지 않는다고 적혀 있으니 괜찮지 않나요?" — 그 문장은 작업 지시이지 잠금장치가 아닙니다. 실제로 무엇을 건드릴 수 있는지는 여러분이 연결한 폴더 범위가 정합니다.

03 · 시작 파일 받기

시작 묶음을 받고 폴더를 만듭니다

지금 세 개만 받으세요. 나머지는 각 단원에서 필요할 때 나옵니다.

meeting-notes-5.zip
회의록 5개 · 모듈 01에서 사용↓meeting-brief.zip
등록용 스킬 · 풀지 않습니다↓file-sort-input-12.zip
파일 12개 · 모듈 05에서 사용↓
1

수업용 폴더를 하나 만듭니다

바탕화면이나 문서 폴더에 HUG_실습 같은 폴더를 하나 만드세요. 오늘 받는 파일을 전부 여기에 모읍니다.

이 상태가 맞습니다: 받은 파일이 다운로드 폴더 여기저기 흩어져 있지 않고 한 곳에 모여 있습니다.

이 폴더는 모듈 05에서 "AI에게 연결할 폴더"를 고를 때 그대로 쓰입니다. 바탕화면 전체나 문서 폴더 전체를 연결하지 않기 위해서입니다.

2

자료 ZIP만 풀고, 스킬 ZIP은 그대로 둡니다

meeting-notes-5.zip과 file-sort-input-12.zip은 풀고, meeting-brief.zip은 풀지 않습니다.

예상 상태:
HUG_실습/회의록_5개/ 안에 .md 5개
HUG_실습/정리전_작업사본/ 안에 파일 12개
HUG_실습/meeting-brief.zip (풀리지 않은 ZIP 1개)
ZIP을 두 번 눌러 창이 열린 것만으로는 "푼 것"이 아닙니다. 그 상태로는 파일 첨부가 안 되거나 첨부해도 내용이 비어 보일 수 있습니다. 반드시 "압축 풀기"를 하세요.
3

파일 개수를 세어 봅니다

폴더를 열고 개수를 직접 세어 보세요. 오늘 내내 "몇 개를 넣었는지"가 결과 검증의 기준이 됩니다.

폴더들어 있어야 할 개수비고
회의록_5개5개01_시작회의 · 02_문안검토 · 03_일정메모_A · 04_일정메모_B · 05_상태확인
정리전_작업사본12개.md 8개 · .csv 3개 · .txt 1개
정상 확인: 두 폴더의 개수가 위 표와 같습니다. 다르면 압축을 다시 풀어 주세요.

04 · 첫 요청 보내기

워밍업 — 첫 요청을 한 번 보내 봅니다

스킬 없이, 파일 하나만 붙여서 짧게 시켜 봅니다. 이번 단계의 목적은 결과의 품질이 아니라 첨부와 새 대화에 익숙해지는 것입니다.

1

새 대화를 열고 파일 하나를 첨부합니다

회의록_5개 폴더에서 02_문안검토.md 한 개만 첨부하세요.

예상 상태: 입력창 위에 파일 이름이 하나 보입니다.
2

아래 문장을 그대로 보냅니다

워밍업 요청
첨부한 파일에 적힌 내용만 사용해서, 확정된 것과 아직 정해지지 않은 것을 나눠서 알려 주세요.
파일에 없는 내용은 만들지 마세요.
예상 상태: 확정된 것으로 제목·소제목·초안 작성 완료가 나오고, 검토 기한은 기록이 없다는 내용이 나옵니다.
3

원본을 열어 한 줄만 맞춰 봅니다

메모장으로 02_문안검토.md를 열어 [B3] 줄을 읽어 보세요.

[B3] 편집역할이 안내문 초안 작성을 완료했다. 검토역할이 초안을 확인하기로 했다. 검토 기한은 기록하지 않았다.
정상 확인: 결과에 "검토 기한"이 정해지지 않은 것으로 들어가 있습니다. 결과가 임의의 날짜를 만들어 냈다면 그것이 오늘 계속 찾아낼 문제 유형입니다.
파일을 못 읽었다고 나오면: 첨부가 안 된 것입니다. ZIP 안에서 바로 끌어다 놓지 않았는지 확인하고, 압축을 푼 폴더에서 다시 첨부하세요.
방금 한 일이 오늘의 축소판입니다.
① 무엇을 쓸지 지정했고 ② "없는 것은 만들지 말라"고 했고 ③ 원본을 열어 한 줄을 맞춰 봤습니다. 모듈 01부터는 이 과정을 매번 말하지 않아도 되도록 스킬에 담아 둡니다.

05 · 막혔을 때

시작 단계에서 자주 막히는 세 가지

① 파일을 첨부했는데 "읽을 수 없다"고 합니다

확인할 것 — ZIP 안에서 파일을 바로 끌어다 놓지 않았나요? 압축을 푼 폴더에서 첨부해야 합니다.

복구 — 압축 풀기를 다시 하고, 풀린 폴더를 열어 파일을 끌어다 놓습니다.

② 다운로드한 파일이 어디 갔는지 모르겠습니다

확인할 것 — 브라우저에서 Ctrl+J를 누르면 다운로드 목록이 열립니다. 항목에서 "폴더 열기"를 누르세요.

복구 — 찾은 파일을 아까 만든 HUG_실습 폴더로 옮깁니다. 오늘 받을 파일이 여러 개라 한 곳에 모아 두는 편이 낫습니다.

③ 파일 이름이 깨져 보입니다

증상 — 회의록_5개가 이상한 글자로 보입니다.

확인할 것 — 오래된 압축 프로그램이 한글 이름을 잘못 읽는 경우입니다. 내용에는 문제가 없습니다.

복구 — Windows 탐색기의 기본 압축 풀기를 쓰거나, 이름이 깨진 폴더를 직접 회의록_5개로 바꿔 주세요. 파일 개수가 5개면 내용은 정상입니다.

이 페이지의 자료 성격과 확인 범위

본문의 실습 자료·스킬·기준 예시·문서는 모두 이번 교육을 위해 만든 교육용 가상 자료입니다. 실제 기관의 업무 자료, 담당자 이름, 연락처, 계정 정보는 들어 있지 않습니다. 표로 적힌 기준 예시는 비교용으로 사람이 작성한 것입니다. 「실제 화면」 표시가 붙은 그림만 개인 계정 리허설(2026-09-15, 2026-09-16)에서 Claude 데스크톱 앱과 Excel·PowerPoint·Word의 Claude 추가 기능을 실제로 찍은 것이며, 사용자 이름·계정 아이콘·다른 대화 제목은 가렸습니다.

기능 설명은 2026-09-15 기준으로 공식 문서를 확인해 적었습니다. 다만 공식 문서에 기능이 있다는 것과 내 계정에서 실제로 성공했다는 것은 다릅니다. 메뉴 이름과 화면 구성은 계정·언어 설정·버전에 따라 다를 수 있으므로, 화면이 다르면 강사에게 알려 주세요. 다른 사람의 계정이나 관리자 암호를 받아 대신 진행하지 않습니다.

파일 존재·ZIP 구조·표의 기준값은 제작할 때 자동 검사로 확인했습니다. 스킬 등록, Cowork 폴더 연결·계획, Excel·PowerPoint·Word 추가 기능의 실행은 개인 계정 리허설에서 확인했고, 회의록 스킬 호출·OCR·Cowork 실행 단계는 아직 리허설 전입니다.
