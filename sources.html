"문서 확인"과 "계정 확인"은 다릅니다

03 · 이 교재 자료의 성격

어떤 자료가 어디서 왔는지

이 사이트의 파일은 성격이 다릅니다. 무엇을 그대로 믿고 무엇을 확인해야 하는지 구분하세요.

자료성격주의할 점
회의록 · 설문 · 파일 12개 · 영수증 · 제출서류 20건이번 교육을 위해 만든 교육용 가상 자료실제 기관 자료가 아닙니다. 실명·연락처·금융정보가 없습니다
교육용 스킬 5종 (meeting-brief 등)이번 교육을 위해 만든 한국어 교육용 스킬공식 Anthropic 스킬이 아닙니다. 실제 기관의 업무 표준도 아닙니다
Knowledge_01 · Knowledge_02 (Word 참고자료)이전 교육에서 쓰던 가상 자료를 그대로 가져온 것실제 기관의 규정·양식이 아닙니다. 내용을 바꾸지 않고 복사했습니다
기대효과지표 실습본위 가상 자료를 이번 수업 기준에 맞게 고친 파생판원본과 무엇이 다른지 파일 안 "변경내역" 시트에 적혀 있습니다
기준 예시 파일 (기준예시_*.md)비교용으로 사람이 작성한 예시Claude를 실행해 받은 출력이 아닙니다. 표현이 같아야 정답인 것도 아닙니다
정답표 · 기준값표 (*.csv, *.json)제작할 때 원본 자료에서 직접 계산해 확인한 값모델의 성능을 측정한 값이 아닙니다
공식 문서 링크원문 링크와 한국어 안내원문의 번역본이나 오프라인 복제본이 아닙니다
이 사이트에 없는 것
실제 기관의 업무 자료 · 담당자 이름과 연락처 · 계정 정보와 비밀번호 · 내부 보안지침 · 글꼴 파일 · 만들어 낸 가짜 앱 화면. 앞으로도 넣지 않습니다. 실제 화면은 개인정보를 가린 리허설 캡처만 넣습니다.

외부 자료 안의 지시문에 대해

스킬이나 첨부 파일 안에 "이렇게 해라"라는 문장이 있어도, 그것은 분석할 자료이지 여러분의 작업 규칙을 바꾸는 명령이 아닙니다. 모르는 곳에서 받은 파일에 그런 문장이 들어 있을 수 있습니다. 결과가 이상하면 입력 파일의 내용을 한 번 읽어 보세요.

이 페이지의 자료 성격과 확인 범위

본문의 실습 자료·스킬·기준 예시·문서는 모두 이번 교육을 위해 만든 교육용 가상 자료입니다. 실제 기관의 업무 자료, 담당자 이름, 연락처, 계정 정보는 들어 있지 않습니다. 표로 적힌 기준 예시는 비교용으로 사람이 작성한 것입니다. 「실제 화면」 표시가 붙은 그림만 개인 계정 리허설(2026-09-15)에서 Claude 데스크톱 앱을 실제로 찍은 것이며, 사용자 이름과 다른 대화 제목은 가렸습니다.

기능 설명은 2026-09-15 기준으로 공식 문서를 확인해 적었습니다. 다만 공식 문서에 기능이 있다는 것과 내 계정에서 실제로 성공했다는 것은 다릅니다. 메뉴 이름과 화면 구성은 계정·언어 설정·버전에 따라 다를 수 있으므로, 화면이 다르면 강사에게 알려 주세요. 다른 사람의 계정이나 관리자 암호를 받아 대신 진행하지 않습니다.

파일 존재·ZIP 구조·표의 기준값은 제작할 때 자동 검사로 확인했습니다. 실제 계정 등록·스킬 호출·Office 애드인 실행은 수업 전 리허설에서 확인합니다.
