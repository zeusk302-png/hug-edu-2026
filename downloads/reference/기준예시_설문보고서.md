# 기준 예시 · 실제 Claude 실행 결과가 아닙니다

수업에서 결과를 비교할 때 쓰라고 작성한 예시입니다. 문장 표현이 같아야 정답인 것은 아니며, 근거와 규칙을 지켰는지가 기준입니다.

종합실습 시나리오 B · 05단계 · 입력: `survey.csv`(24행) + `DATA_DICTIONARY.md` → 편집 가능한 집계 xlsx + 차트 1개 + 짧은 보고서

같은 내용을 수식으로 만든 파일이 `설문_집계_기준본.xlsx`(응답·집계·분포 시트)입니다. 값은 04단계 요약과 같아야 합니다.

## 처리 현황과 유효 응답 분포는 다른 표입니다
| 처리 현황 | 값 | 집계 시트 셀 |
|---|---|---|
| 전체 행 | 24 | B4 |
| 완전 중복 행(R05가 그대로 한 번 더) | 1 | B5 |
| 중복 제거 후 | 23 | B6 |
| 만족도 누락(R21) | 1 | B7 |
| 범위 오류(R22, 만족도 6) | 1 | B8 |
| **유효 만족도 응답(분모)** | **21** | B9 |
| 만족도 합 | 83 | B10 |
| 평균 | 3.95 | B11 |
| 4~5점 건수 / 비율 | 15건 / 71.4% | B12 / B13 |

| 유효 응답 분포 | 건수 | 비율(%) | 분포 시트 셀 |
|---|---|---|---|
| 1점 | 0 | 0.0 | B4 / C4 |
| 2점 | 2 | 9.5 | B5 / C5 |
| 3점 | 4 | 19.0 | B6 / C6 |
| 4점 | 8 | 38.1 | B7 / C7 |
| 5점 | 7 | 33.3 | B8 / C8 |
| 합계 | 21 | 99.9 | B9 / C9 |

비율 합이 100.0이 아니라 99.9인 것은 반올림 때문이며 오류가 아닙니다. 보고서에 "반올림으로 합이 100이 되지 않을 수 있음"을 적습니다.

## 차트 (예)
- 종류: 세로 막대 · 제목 **"만족도 분포 (유효 응답 21건, 건수)"** — 제목에 분모가 있어야 합니다
- 원본 범위: 분포!A4:A8(점수) · 분포!B4:B8(건수). 처리 현황(집계 시트)이나 응답 시트 원본은 포함하지 않음
- 값 축: 건수, 0부터 시작 · 1점이 0건이라도 항목을 빼지 않음(다섯 항목)

## 짧은 보고서 (예 — 문장 5개 이내)
1. 유효 만족도 응답 21건(전체 24행에서 완전 중복 1, 누락 1, 범위 오류 1 제외)을 기준으로 집계했습니다. (집계!B4~B9)
2. 평균 만족도는 3.95점이며, 4~5점 응답이 15건으로 71.4%입니다. (집계!B11·B12·B13)
3. 분포는 4점 8건, 5점 7건, 3점 4건, 2점 2건, 1점 0건입니다. (분포!B4:B8)
4. 비율 합은 반올림 때문에 99.9%로 표시됩니다.
5. 교육용 가상 설문 24행이며 전체 참여자를 대표하지 않습니다. 선호시간 문항은 이 보고서에서 다루지 않았습니다.

"만족도가 높다", "성공적" 같은 평가와 원인 분석은 넣지 않습니다. 분모를 23이나 24로 바꾸면 비율이 달라지므로(04단계) 어느 분모를 썼는지 첫 문장에 적습니다.

## 차트 여섯 가지 확인
1. 제목에 무엇의 분포인지와 분모(유효 응답 21건)가 있는가.
2. 원본 범위가 분포 시트의 유효 응답 건수인가(처리 현황·원본 행이 아님).
3. 항목이 1~5점 다섯 개 모두 있는가(0건인 1점 포함).
4. 값 축이 0부터 시작하고 단위(건수)가 적혀 있는가.
5. 막대 값이 분포 시트의 건수와 같은가(0·2·4·8·7).
6. 응답 시트 값을 바꾸면(예: R21 만족도에 4 입력) 집계·분포·차트가 함께 바뀌는가 — 바뀌지 않으면 값 복사.

## 검증 항목 (학생이 직접 확인)
1. 집계 시트 B9가 `=COUNTIF(응답!E2:E25,"유효")` 같은 수식인가(값이 아님).
2. 처리 현황 표와 유효 응답 분포 표를 섞어 쓰지 않았는가.
3. 보고서의 숫자마다 시트·셀 주소가 있는가.
4. 파일 이름에 조 이름을 넣어 별도 저장했는가(원본 survey.csv는 그대로).
