# 기준 예시 · 실제 Claude 실행 결과가 아닙니다

수업에서 결과를 비교할 때 쓰라고 작성한 예시입니다. 문장 표현이 같아야 정답인 것은 아니며, 근거와 규칙을 지켰는지가 기준입니다.

적용 스킬: `file-sort-plan` · 입력: `file-sort-input-12.zip`의 12개 파일

이 스킬은 **계획만** 만듭니다. 파일을 실제로 옮기거나 이름을 바꾸지 않습니다.
표의 모든 값은 `파일정리_기준표_12건.csv`와 같습니다.

## 확인해야 하는 다섯 가지
1. 표의 행이 **12행**입니다. 입력 파일 수와 같아야 합니다. 스킬이 만든 보고서는 입력 수에 넣지 않습니다.
2. `memo_a.md`와 `memo_b.md`는 종류·날짜·제목이 같아 제안 이름이 겹칩니다. `_01`, `_02`로 구분하고 **어느 쪽도 지우지 않습니다.**
3. 날짜가 문서 안에 없으면 `날짜미상_`으로 시작합니다. 파일 수정일을 문서 날짜로 바꿔 쓰지 않습니다. (`회의메모_날짜없음.md`, `list_unknown.csv`, `read_later.txt`, `report_misc.md` 4건)
4. 확장자를 바꾸지 않습니다. `.csv`는 `.csv`로, `.txt`는 `.txt`로 남습니다.
5. 폴더는 회의록 / 보고서 / 목록 / 기타 네 가지입니다. 회의록 3 · 보고서 3 · 목록 3 · 기타 3으로 나뉩니다.
