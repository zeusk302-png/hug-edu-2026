# 기준 예시 · 실제 Claude 실행 결과가 아닙니다

수업에서 결과를 비교할 때 쓰라고 작성한 예시입니다. 문장 표현이 같아야 정답인 것은 아니며, 근거와 규칙을 지켰는지가 기준입니다.

적용 스킬: `meeting-brief-manager` (학생이 양식 순서·열을 직접 고친 판) 또는 따라잡기용 `meeting-brief-manager-ref` · 입력: 회의록 5개

**3문장판과 달라져야 하는 곳은 "첫 표가 결정 사항 표"라는 점과 그 표의 열 네 개입니다.** 핵심 요약(3문장)·확정 사항·할 일·읽은 자료는 3문장판과 같아야 합니다.

## 2. 핵심 요약
안내문의 제목과 소제목은 확정되었고 초안 작성은 완료되었습니다. [02_문안검토.md · B1–B3]
안내 발송 예정일은 3주차 화요일과 수요일로 다르게 적혀 있으며 최종 승인 기록이 없어 확정 여부를 확인해야 합니다. [03_일정메모_A.md · C1; 04_일정메모_B.md · D1; 05_상태확인.md · E3]
장소, 사진 사용 여부, 참여 인원과 예산은 추가 확인이 필요합니다. [03_일정메모_A.md · C2; 04_일정메모_B.md · D2; 05_상태확인.md · E2]

## 검증 항목 (학생이 직접 확인)
1. 첫 표가 "결정이 필요한 사항"이고 열이 결정할 내용 / 현재 막힌 이유 / 확인할 역할 / 원문 근거 네 개인가.
2. "확인할 역할" 열에 원문에 있는 역할(검토역할·진행역할·편집역할)만 있는가. "팀장"·"담당자"처럼 원문에 없는 역할이 생겼으면 오답.
3. "현재 막힌 이유"가 원문의 사실만 말하는가. "화요일로 확정하면 됩니다" 같은 해결책이 들어갔으면 오답.
4. 2~4번 표와 읽은 자료 수가 3문장판과 같은가. 여기까지 달라졌다면 양식을 지나치게 고친 것.
