# 교육용 가상 설문 — 데이터 사전
실제 인물·기관과 관계없는 가상 데이터입니다. 응답ID는 합성 식별자이며 개인정보가 아닙니다.
만족도는 정수 1~5, 조는 A/B/C, 선호시간은 오전/오후입니다. 같은 내용이 완전히 복제된 행은 첫 행만 남깁니다.
공백 만족도는 누락, 6은 범위 오류입니다. 둘 다 만족도 평균·분포 분모에서 제외하고 각 건수를 보고합니다. 같은 ID이면서 다른 응답이면 삭제하지 말고 충돌로 처리하지만 이 묶음에는 그 사례는 없습니다.
전체 행 24, 완전 중복 1, 중복 제거 후 ID 23, 유효 만족도 21, 누락 1, 범위 오류 1. 자세한 기준값은 expected.json에 있습니다. 기준값은 제작 시 계산했으며 Claude 추론 성능을 측정한 값이 아닙니다.
기준 질문: ‘만족도 4~5점 비율은?’ 분모는 21입니다. 23 또는 24로 나누면 이 기준에서 오답입니다.
